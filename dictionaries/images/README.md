## 1. Raw Data vs Meaning Diagram

Left side:

```text
18
42
ONLINE
```

Right side:

```python
{
    "battery": 18,
    "temperature": 42,
    "gps": "ONLINE"
}
```

Purpose:
Show how dictionaries attach meaning to data.
